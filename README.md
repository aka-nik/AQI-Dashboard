# Air Quality Monitoring Dashboard 
An interactive dashboard for exploring air quality data across 45+ cities and multiple states in India. 
The dashboard presents AQI statistics, pollutant levels, monthly trends, city-wise comparisons, and station distributions across different air-quality categories. 
## Dashboard Preview !
[Air Quality Monitoring Dashboard](dashboard-screenshot.png) 
## Features 
- Total number of monitoring stations.
- Average AQI across the dataset.
- Average PM10 and PM2.5 concentrations.
- State-wise average AQI comparison.
- City-wise average AQI comparison.
- Monthly AQI trend analysis.
- Pollutant comparison for CO, NO2, OZONE, PM10, PM2.5, and SO2.
- AQI category distribution by city. - Station count across AQI categories.
- Filters for state, city, dominant pollutant, and date.

## Key Metrics The dashboard currently displays:

## AQI Categories 
The dashboard groups monitoring stations into the following categories: 
- Good
- Moderate
- Unhealthy for Sensitive Groups
- Unhealthy
- Very Unhealthy 
- Hazardous

## Data Analysis 
The dashboard is designed to help users: 
- Identify locations with higher pollution levels.
- Compare air quality between cities and states.
- Study changes in AQI across months.
- Understand the contribution of major pollutants.
- Examine how monitoring stations are distributed across AQI categories.
